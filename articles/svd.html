Image approximation with SVD

An image approximation project using SVD (singular value decomposition).

GitHub repository ↗

Try it

Upload an image and change the rank to see the approximation.

Preparing the example image…

SVD uses the image's original pixel dimensions. The input preview shows the same grayscale pixels used by SVD. For browser performance, use images up to 512 pixels on the long side and 288 on the short side. Uploaded images stay in your browser.

I built an SVD class to make low-rank approximations of images. Lower ranks keep broad shapes; higher ranks bring back more detail. MORE DETAILED ARTICLE COMING SOON!

The interactive preview above lets you try this with your own image. The Python code and Streamlit app are in the project repository.
